# Ключевые слова для поиска запросов — ВИТАПРОМ

Одностраничная презентация: по каким словам искать чужие запросы на запчасти
для газовых и жидкотопливных котлов и горелок.

Четыре слоя — от точного к широкому: серии артикулов, связки «бренд + тип»,
бренды латиницей и кириллицей, типы изделий и отраслевые фразы.

Публичная версия: только ключевые слова, количественные показатели не приводятся.
